# KEWW UI review

[Open the free preview](https://leozh0u.github.io/keww-ui-review/).

Static website prototype for UI consultation. It does not replace workwithkeww.com.

“Make better staffing decisions.” introduces a larger laptop above the phone and
watch. The laptop uses an illustrative studio hardware render with a realistic
keyboard and a separate HTML KEWW interface. Scroll movement is restrained. The
existing task-through-event watch sequence leads into the explorable workspace
and service photographs.

Staffing, Tasks, Hours and Watch updates use fictional example records. Complete
and reset a sample task to see its source record and total change. The homepage
preserves contingent staffing, software for an existing team and industry add-ons.
Kasheww is in pilot; native watch integration and expanded analytics remain in
development. Product illustrations are not evidence of released native clients
or live employee data.

Applications and inquiries are disabled. Entries and uploads stay in browser
memory. The role list is a read-only snapshot. Find Work opens the complete review
application, which links the original live KEWW form for real submissions. The
review creates no worker accounts or email. Backend source, credentials, private
assessment answers and applicant records are excluded.

Tina's supplied KEWW palette is retained. The local Lato font remains provisional;
its OFL notice ships under docs/assets/fonts. Three.js is MIT licensed, with its
notice under docs/assets/vendor/three-LICENSE.txt. Watch stills are code-rendered
concepts. The laptop and overhead event-floor images are generated illustrations;
Cafe Natalie service photographs are retained from existing source media.

Keyboard controls, reduced-motion views and no-JavaScript content are preserved.
