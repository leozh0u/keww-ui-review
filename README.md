# KEWW UI review

Static website prototype for UI consultation.

[Open the preview](https://leozh0u.github.io/keww-ui-review/).

Applications and inquiries are disabled. Form entries and uploads stay in browser memory. The role list is a read-only catalog snapshot; no worker accounts or email are created.

Only public review assets are included. Production APIs, credentials and private assessment answers are excluded. Existing Cafe Natalie photographs and KEWW branding are retained; Lato licensing is included under docs/assets/fonts. This prototype does not replace workwithkeww.com.

The business homepage follows an illustrative event task through a scroll-driven
3D watch concept and manager view, with localized static and reduced-motion
fallbacks. Watch integration and expanded analytics remain in development;
Kasheww is in pilot. Hardware geometry is conceptual. The shared palette follows
Tina's supplied KEWW colours; the existing local font is provisional.

Three.js is MIT licensed; its notice ships in docs/assets/vendor/three-LICENSE.txt.
The translated watch stills are code-rendered from the same authored scene, not
photographs of verified supplied hardware or private Figma exports.
