# KEWW UI review

Static website prototype for UI consultation.

[Open the preview](https://leozh0u.github.io/keww-ui-review/).

Applications and inquiries are disabled. Form entries and uploads stay in browser memory. The role list is a read-only catalog snapshot; no worker accounts or email are created.

Only public review assets are included. Production APIs, credentials and private assessment answers are excluded. Existing Cafe Natalie photographs and KEWW branding are retained; Lato licensing is included under docs/assets/fonts. This prototype does not replace workwithkeww.com.

The business homepage follows an illustrative event task through a scroll-driven
3D watch concept and manager view, with localized static and reduced-motion
fallbacks. Watch integration and expanded analytics remain in development;
Kasheww is in pilot. Hardware geometry is conceptual. The shared palette follows
Tina's supplied KEWW colours; the existing local font is provisional.

Three.js is MIT licensed; its notice ships in docs/assets/vendor/three-LICENSE.txt.
The translated watch stills are code-rendered from the same authored scene, not
photographs of verified supplied hardware or private Figma exports.

The homepage distinguishes contingent staffing, workforce software for an existing
team and industry add-ons, with Kasheww as the catering pilot. Bold worker entry
opens the review application, which links the current live KEWW application for
real submissions. The static review itself still sends nothing.

The overhead event-team illustration is AI-generated and labelled as illustrative.
It is not actual staff/customer photography, verified device hardware or a live
location-tracking view. Watch context cleanup includes an explicit GPU-context
release on intentional teardown and ignores events from retired canvases.

The homepage now leads with “Make better staffing decisions.” and an interactive
KEWW app illustration. Staffing, Tasks and Hours views use fictional example
records. Complete a sample task to see its source record and total change, then
reset it. Four assigned crew account for 32 planned and 30 recorded example hours.
The watch remains a supporting workflow chapter. Availability text sits outside
the animation. Bold Find Work is immediately before Watches and opens the
localized application. No live data is fetched by the product illustration.

App layers, data comparisons, documents and staff photographs use bounded native
scroll motion. Tabs and local task actions work with a keyboard and reduced
motion; all three example views remain readable without JavaScript.

The hero includes desktop/laptop, phone and watch product illustrations. The
phone and watch appear first on smaller screens. Watch updates is a fourth
interactive sample view, separating assignment, opening and completion records.
An earlier service-photo section uses existing Cafe Natalie photographs with
bounded scroll motion. These are illustrations and fictional records, not a
claim of released native clients or live watch reporting.

The latest opening uses “Make better decisions.”, leads with the watch and goes
straight into the existing task-through-event sequence before the app/data and
service-photo sections. The smaller laptop has a visible keyboard and trackpad;
its lid opens with the initial scroll and remains open in static fallbacks.
