常见问题。

可以申请兼职吗？

可以。请在申请中填写可工作时间和偏好的时段。具体工作取决于当前机会。

可以选择多个岗位吗？

可以。选择你感兴趣的岗位，技能问题会根据所选岗位安排。

需要先注册应用账号吗？

网站申请与应用登录相互独立。已有账号可在此登录。

岗位列表无法加载怎么办？

请在申请中选择重试。如果仍未显示，请联系 hello@workwithkeww.com。系统不会使用未经确认的岗位提交申请。
