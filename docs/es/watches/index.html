¿Qué está disponible ahora?

La integración con relojes sigue en desarrollo. La compatibilidad, las fechas y las condiciones de compra o suscripción aún no se han confirmado. Solicita una demo para hablar del flujo previsto y tus necesidades.

KEWW también ofrece software para equipos existentes y una opción independiente de personal temporal. No necesitas adoptar relojes para consultar sobre estas opciones.

Preguntas sobre los relojes.

¿Puedo pedir o activar un reloj aquí?

No. Esta página presenta un producto en desarrollo. Contacta con KEWW para hablar de tus necesidades y confirmar la disponibilidad.

¿La ilustración muestra una actualización en vivo?

No. Usa datos de ejemplo para explicar el flujo previsto. No está conectada con un trabajador, dispositivo o evento real.

¿Podemos usar KEWW sin relojes?

Sí. Puedes consultar sobre software para tu equipo o solicitar personal temporal independientemente del desarrollo de los relojes.
