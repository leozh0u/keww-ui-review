Solicitar trabajo.

¿Qué necesito antes de empezar?

Tus datos de contacto, preferencias de trabajo, tarjeta de manipulador de alimentos y tres referencias profesionales. De cada referencia necesitas nombre, empresa, correo, teléfono y cómo te conoce. Puedes adjuntar currículum, certificado TABC y carta de presentación. Ver la guía.

¿Puedo volver y cambiar una respuesta?

Sí. Usa Atrás o un paso completado. Los datos se mantienen entre pasos, pero no se guardan al salir o actualizar la página.

¿Qué archivos puedo subir?

La tarjeta de manipulador de alimentos y el certificado TABC admiten PDF, JPG o PNG. El currículum y la carta de presentación admiten PDF, DOC o DOCX. El límite es de 10 MB por archivo y 18 MB en total.

¿Están traducidas las preguntas del cuestionario?

Las preguntas originales de cada puesto están actualmente en inglés. La web y los controles de solicitud están disponibles en inglés, español y chino simplificado. Si necesitas ayuda antes de solicitar, escribe a hello@workwithkeww.com.

¿Qué hago si no se confirma el envío?

Conserva la referencia que muestra la página y contacta con hello@workwithkeww.com. Si se necesita una revisión manual, no envíes otra solicitud hasta que el equipo la compruebe.

Personal y software.

¿Qué debo incluir en una consulta de personal?

Ubicación, fechas, puestos y número aproximado de personas, junto con tu local y datos de contacto. El equipo debe confirmar cobertura y disponibilidad. Enviar una consulta.

¿Pedir una demo o prueba crea una cuenta?

No. Son solicitudes para hablar con KEWW. No reservan personal, crean una cuenta ni activan una prueba.

¿Cómo consulto precios o cobertura?

Describe tus necesidades en el formulario. Los precios y la disponibilidad se confirman según ubicación y requisitos; no hay una lista pública aquí.

Tu cuenta.

¿Dónde inician sesión los usuarios actuales?

Abre la aplicación KEWW. El acceso a la aplicación es independiente de las solicitudes de trabajo y consultas comerciales de esta web.

¿Cómo contacto con KEWW?

Para preguntas generales o ayuda con esta web, escribe a hello@workwithkeww.com. Para personal o software, usa el formulario de consulta. Esta página no promete un plazo de respuesta.
